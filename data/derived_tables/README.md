# Derived Tables

The files in `original_legacy/` were copied from the local TRR-FEEDBACK paper folder:

- `feedback_tables_and_figures_lotus123.wk3`: legacy Lotus 1-2-3 workbook containing table and figure data.
- `paper_tables_word5.doc`: legacy Word 5 table document.

The files in `modernized/` are readability sidecars produced with LibreOffice:

- `feedback_tables_and_figures_lotus123.xlsx`
- `paper_tables_word5.txt`
- `csv/Sheet1.csv`
- `workbook_sheet_summary.json`

These are aggregate paper outputs, not raw source data.
